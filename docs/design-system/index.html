Building cards

The operating model sits on the face of the card because it decides whose money the rent is. Note the third figure changes with it: a head-leased building reports gross margin, an owner-managed one reports rent administered for the landlord. Showing a margin on an owner-managed building would report the landlord's income as the company's.

Control outline

Interactive outlines use --sin-border-control at 3:1, which WCAG 1.4.11 requires of a control boundary. Dividers stay quieter; a hairline at 3:1 would be loud.
